# Bootstrap the merged agent governance framework

## Summary
Creates the merged governance framework: risk tiers T0-T3, verification gates G0-G8 (including the new diff-faithfulness gate), the change-manifest workflow, the hash-chained append-only audit log, the zero-dependency validator, the CI pipeline, and explicit human judgment boundaries -- assembled by combining two prior designs after adversarial testing found specific, demonstrated bypasses in each, and closing them.

## Why
Autonomous agents need properties like "correct" and "secure" defined as checkable mechanisms. Two prior designs were tested directly (not just read): one's diff-derived risk classifier read its own rules from the diff being judged, and its human-approval field was a self-writable string, so a forged approval on an auth-boundary change was accepted. The other had a rigorous manifest and audit trail with a genuinely zero-dependency validator, but never compared the manifest's claimed scope to the actual diff, so a manifest declaring "docs only" while a guardrail file was also edited passed cleanly. This framework keeps the second design's engineering (real CI wiring, real tests, no dependencies) and adds the first design's idea back in with both bypasses closed: rules are read from the base commit, approval requires an external reference CI resolves independently, and gate G8 cross-checks the manifest against the real diff.
